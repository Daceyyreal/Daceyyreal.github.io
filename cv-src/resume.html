PROJECTS

splat-slim Python · Typer · NumPy · pytest + ruff CI

Command-line tool and library that compresses trained 3D Gaussian Splatting models by ~74% with under 3 dB quality loss, with no retraining. Implemented a self-decodable mixed-precision quantization format that stores per-group ranges in a sidecar .meta.npz, so compressed files still load in standard viewers.

Shipped with automated tests and linting on GitHub Actions, MIT-licensed, with a tagged v0.1.0 release.

nerf-prep Python · Docker · GitHub Actions · GHCR

Packaged a fragile multi-tool pipeline (COLMAP to Nerfstudio) into one reproducible Docker command, published to GHCR by CI. Handles matcher selection by capture type, GPU/CPU auto-detection with CPU fallback, headless operation, input validation, and a registration-rate summary.

Verified end to end on a real 40-photo capture: 40 of 40 images registered.

splat-lab TypeScript · Three.js · Vite · live demo

Browser-based, real-time demo of the compression pipeline: load a scene, move sliders, and watch file size and visual quality trade off live on the GPU. Ported the Python compression math to TypeScript; runs entirely client-side with no backend.

paper-chat Python · Streamlit · sentence-transformers · PyMuPDF

Retrieval-augmented question answering over a PDF library, where every answer cites the exact paper and page it came from and declines when the sources do not cover the question. Swappable LLM backend (Groq or Gemini) behind a small interface, so the retrieval and citation logic is unit-tested with fakes and needs no API key to run.
